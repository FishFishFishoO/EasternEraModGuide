# UE4SS

**UE4SS** is a free tool that runs **inside the game** while you play.
In this guide we use it for one job: **making a new mapping file (`.usmap`) for FModel** after a game update.

Why this matters: the mapping file stops working when the game updates. With this guide, **anyone** can make a new one. You don't have to wait for someone else.

| Guide | What it covers |
|---|---|
| [1. Setup](1-Setup.md) | Download, install, and the settings you **must** change for Eastern Era |
| [2. Make a new mapping file](2-MakeMapping.md) | Create the `.usmap`, use it in FModel, share it |

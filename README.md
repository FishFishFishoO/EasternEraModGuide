# Eastern Era Modding Guide

A beginner-friendly, step-by-step guide to modding **[Eastern Era](https://store.steampowered.com/app/3446240/Eastern_Era/)**.
No experience needed. Stuck? Open an [Issue](../../issues) and ask!

> Fan-made guide. Not made by or affiliated with the Eastern Era developers.
> Official Mod Kit: **[L1ngan/EasternEraMod](https://github.com/L1ngan/EasternEraMod/tree/main)**

---

| [2. How to use it](UnrealEngine/2-HowToUse.md) | Create a mod, fill in Mod Info, package, test in game, publish to Workshop |

# Mapping Files (.usmap)

FModel needs these to read Eastern Era's files. How to use them: **[FModel Setup, Step 4](../1-Setup.md#step-4--link-the-mapping-file)**.

| File | Game build | Unreal | Made with | Added |
|---|---|---|---|---|
| [`EasternEra-5.6.1-44394996.usmap`](EasternEra-5.6.1-44394996.usmap) | 44394996 | 5.6 | UE4SS v3.0.1-1111 | 2026-09-30 |

**Which one?** The newest (top row), unless you play an older game version.

**To download:** click the file name, then **Download raw file** (⬇ button, top right).

**After a game update** FModel may show errors. Get a newer file here, or **make your own**: [UE4SS guide](../../UE4SS/README.md).

> These files only contain the *names* of the game's data fields so tools can read them. No game art, models, or code.
